# Platform adapter rules

Use one stable `<card-slug>-<role-slug>` identifier per generated role. Each agent must say it is personal, point to its profile in `~/.agent-factory/avatars/<card-slug>/`, bind the active project at task time, list the quality/approval boundary, and contain only knowledge-reference locations.

## Claude Code

Write Markdown subagents below `~/.claude/agents/agent-factory/` with quoted YAML `name` and `description` frontmatter. Use `CLAUDE.md` for a project overlay when needed; do not assume Claude Code reads `AGENTS.md`.

## OpenCode

Write Markdown agents below `~/.config/opencode/agents/agent-factory/`. Verify the installed OpenCode release’s agent-frontmatter fields before writing; current project context is supplied at runtime.

## Codex

Write TOML agents below `~/.codex/agents/`. Include `name`, `description`, and `developer_instructions`. Verify the installed Codex release’s optional tool/skill configuration before adding it.

## Conflict handling

Before every write, display path, whether it exists, and whether it was generated by this profile. Never overwrite an unrecognized or user-modified file without an explicit confirmation. Preserve the prior generated version for rollback when overwriting is approved.
