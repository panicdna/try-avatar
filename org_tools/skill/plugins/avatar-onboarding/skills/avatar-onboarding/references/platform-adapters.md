# Platform adapter rules

Use one stable `<card-slug>-<role-slug>` identifier per generated role. Each agent must say it is personal, point to its profile in `~/.agent-factory/avatars/<card-slug>/`, bind the active project at task time, list the quality/approval boundary, and contain only knowledge-reference locations.

## Claude Code

Write Markdown subagents below `~/.claude/agents/agent-factory/` with quoted YAML `name` and `description` frontmatter. Use `CLAUDE.md` for a project overlay when needed; do not assume Claude Code reads `AGENTS.md`. `install_avatar.py` renders an explicit `tools:` allow-list (the base bundle plus any named Skills) rather than leaving the field out -- omitting it entirely makes the subagent inherit every tool of the spawning session. `Agent` and `SendMessage` are excluded from that list unless the role's `allow_delegation` is `true`, which is how an installed avatar would otherwise end up able to recursively spawn its own subagent.

## OpenCode

Write Markdown agents below `~/.config/opencode/agents/agent-factory/`. Verify the installed OpenCode release's agent-frontmatter fields before writing; current project context is supplied at runtime. Apply the same default-deny-delegation principle as Claude Code: find OpenCode's current equivalent of a per-tool allow/deny map (its docs use a `tools:` boolean map, e.g. disabling a `task`-type tool) and restrict subagent-spawning capability by default -- do not leave it unrestricted by omission just because the exact key wasn't in this file yet.

## Codex

Write TOML agents below `~/.codex/agents/`. Include `name`, `description`, and `developer_instructions`. Verify the installed Codex release's optional tool/skill configuration before adding it, and apply the same default-deny-delegation principle as Claude Code once Codex's equivalent field is confirmed.

## Conflict handling

Before every write, display path, whether it exists, and whether it was generated by this profile. Never overwrite an unrecognized or user-modified file without an explicit confirmation. Preserve the prior generated version for rollback when overwriting is approved.
